# v006_keep_verified_options

가설: PM 승인 대기를 새 설계로 오인하지 않고 보충 생성 실패 시 검증 후보를 보존·재평가한다. 이관된 업무의 이중 합산과 실제 실행이 같은 중복 후보를 제거한다.

실행 결과는 이 버전의 experiments/ 아래 저장합니다. 실제 Live, Mock, 모의 당사자 승인은 구분합니다.

실제 Live 5개 실행 결과: T1/T2/T3는 PM 선택 대기, T5는 Dev·QA 제약 검토 후 PM 전달. T4는 검증 후보가 있었으나 평가 응답의 후보 ID 오류로 중단했습니다. 준비 기준 4/5이며 실제 적용 성공률이 아닙니다. 일부 동의 응답은 다른 사람 승인을 본인 NEEDS_INPUT으로 혼동했습니다. v007에서 후보 참조 피드백 1회 복구와 본인 권한 해석을 보완합니다.
