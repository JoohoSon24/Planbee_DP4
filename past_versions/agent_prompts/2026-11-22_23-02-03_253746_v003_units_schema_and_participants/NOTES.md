# v003_units_schema_and_participants

가설: Live v002의 일/시간 혼동과 잘못된 plan_actions.kind를 MD로 명확히 하고 한 번의 필드 오류 피드백 복구만 허용한다. 무관한 업무 이동을 제한해 실제 당사자만 토론한다.

실행 결과는 이 버전의 experiments/ 아래 저장합니다. 실제 Live, Mock, 모의 당사자 승인은 구분합니다.

## 실제 Live 결과와 다음 수정 근거

T2/T3/T4는 유효 후보를 당사자 검토 후 PM에게 제출했고 T5는 Dev·QA 발언을 거쳐 PM 전달했습니다. 실제 적용/사람 승인은 수행하지 않았습니다. T1은 다시 6h→8h가 되어 실패로 기록했습니다.

원인을 분리한 재현 테스트에서, 후보 배치 함수 외에 **재견적의 반일 반올림**도 같은 6h를 8h로 바꾸는 것을 확인했습니다. 원래 견적과 같으면 변경 없음으로 처리하고 M4의 2h 시간 단위를 보존하도록 수정합니다.

또한 schema 오류 이벤트를 저장할 때 ctx가 복사되어 복구 호출의 예산 증가가 누락되는 결함을 재현했습니다. v003의 기록 호출 수는 실제 HTTP 시도 수보다 작을 수 있으므로 비용/정확한 호출 통계로 사용하지 않습니다. 다음 버전은 bound된 원본 카운터를 성공·실패 모두에서 되돌려 저장합니다. 새 회귀 테스트 두 개가 기존 코드에서 실제 실패한 뒤 수정했습니다.
