# v005_classify_duration_change_first

가설: 재견적 응답에서 실제 소요량 변경 여부를 먼저 분리하면 단순 일정 이동에서 모순된 숫자를 적용하지 않는다. 나머지 시나리오의 실제 소요 증가는 유지하고 모든 결과를 Live로 검증한다.

실행 결과는 이 버전의 experiments/ 아래 저장합니다. 실제 Live, Mock, 모의 당사자 승인은 구분합니다.

## 실제 Live 결과

T1은 6h를 유지한 단독 이동 후보로 처음 실제 Live 기준을 충족했습니다. T2/T4와 T5도 기준 충족. T3은 이미 이관 후보가 있고 GD도 공개 동의했으나, ANSWER 발언에 붙은 requires_new_candidate 플래그 때문에 불필요하게 보충 생성을 시작했고 그 출력 형식이 실패해 run 전체가 종료됐습니다. 실패와 원래 후보 4개를 함께 보존했습니다.

다음 버전은 실제 CONDITION 발언에만 보충 생성을 허용합니다. 보충 실패 시 기존 검증 후보를 버리지 않고 새 공개 조건으로 다시 평가·동의받습니다. 이관된 업무량을 Alpha에 이중 합산하지 않도록 MD와 facts를 명시합니다. 실제 실행이 같은 후보의 장식적 설명/무효한 release 힌트 중복도 제거합니다.
