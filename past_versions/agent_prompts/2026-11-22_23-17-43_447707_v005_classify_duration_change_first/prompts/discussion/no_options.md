현재 생성기가 하드 제약을 만족하는 후보를 찾지 못했다. 이것은 전체 가능성의 수학적 증명이 아니다. self의 위임카드·역할 지침·공개 보드·앞선 공개 대화를 읽고, 요청자 또는 후속 검증 담당자로서 필요한 확인을 새 발언으로 남겨라.

원 담당자는 현재 가능한 완료 시점과 후속 담당자에게 확인할 질문을 말한다. 후속 담당자는 실제 필요한 시작/완료와 양보할 수 없는 검증 범위를 답한다. 앞 발언을 무시하고 같은 실패 설명을 반복하지 않는다. reason이나 비공개 카드 원문 대신 공개 가능한 일정·산출물·권한 조건을 말한다.

recipient는 공개 참가자 ID 또는 pm이다. required_decision에는 PM이 결정해야 할 사항(예: 릴리스 보류 검토와 공식 milestone 변경의 별도 상위 승인)을 구분한다. 후보가 없는데 수락이나 적용을 꾸미지 않는다. “못 풂”이라는 단정만 하지 말고 실제 제약 충돌과 아직 탐색하지 못한 연산이 있다면 그 한계를 말한다.
