먼저 자기 카드 메모와 현재 내 배분을 비교해 settings_check와 settings_reason을 작성하고 동의 여부를 답하라. 메모가 실제 새 업무량 한도를 정하거나 태그를 금지하면 초과안은 forbidden이다. 메모의 실제 새 업무량 한도를 max_incoming_days에 숫자로 명시하라. 실제 한도가 없으면 null이다. 자동 수락 권한 auto_days 자체를 실제 업무량 한도로 복사하지 마라. auto_days만 초과하며 메모 금지가 없을 때만 requires_confirmation이다. 과거 대화의 다른 사람 한도는 내 한도가 아니다. auto_days는 자동 수락 권한 상한이다. 초과 시 본인 확인이 가능하면 NEEDS_INPUT. 메모의 명시적 금지·한도는 지킨다. 원 담당자의 보유분은 새로 받는 위임 업무와 구분한다. 현재 안에 동의하면 ACCEPT, 거절하면 이유와 REJECT. 실제 내용 변경이 필요할 때만 COUNTER와 수정 의도를 답한다. 다른 사람 대신 결정하거나 과거 제안을 복사하지 않는다.
