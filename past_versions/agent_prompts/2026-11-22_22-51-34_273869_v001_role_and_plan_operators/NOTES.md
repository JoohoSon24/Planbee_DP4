# v001_role_and_plan_operators

가설: 개인별 MD와 실제 범위/검증/단계별 연산, 단독 이동의 참여자 축소로 T1~T4 유효 후보를 만들고 T5는 Dev·QA 설명 뒤 PM 보류 검토로 종료한다.

실행 결과는 이 버전의 experiments/ 아래 저장합니다. 실제 Live, Mock, 모의 당사자 승인은 구분합니다.

## v001 실험 결과

- Mock 전체 검사: T2/T3/T4의 유효 후보와 T5 PM 전달 확인. T1은 6h→8h 변형으로 실패.
- 실제 Live T1: 5회 호출, 20.77초, PM 대기까지 진행했으나 같은 6h→8h 변형이 있어 기대 결과 실패로 기록. 적용하지 않음.
- 원인: 같은 담당자에게 유지하는 업무에도 반일 단위 숙련도 환산 함수를 적용함. 이는 프롬프트만으로 고칠 수 없는 생성 코드 문제.
- 다음 가설: 동일 담당자의 업무량은 정확히 유지하고, Dev MD도 임의 소요 증가를 거절하도록 보완한다.
- Live 첫 샌드박스 연결 실패와 실험 스크립트 None 처리 오류는 RUNNER_ERROR.md로 별도 보존. 실제 모델 성공률과 혼합하지 않음.
