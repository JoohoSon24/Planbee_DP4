## (1) T1 - Re plan for a goal change

PM 입력 : 금요일 데모에서 기존 메뉴 화면 대신 **정적 스킨 상점 미리보기 화면**을 보여주고 싶습니다. 결제나 서버 상점 기능은 필요 없습니다. 기존 P0 기능과 QA는 유지해 주세요.

- 시스템이 보여줄 대안(예시)

| 조정 | 담당·작업량 | 일정 | 선행 조건 / 이유 |
| --- | --- | --- | --- |
| `B2` 메뉴 P1을 이번 데모에서 제외 | Ben 1일 해제 | 수 오후·목 오전 | PM의 목표 변경에 따른 P1 교체 |
| `N1` 기존 스타일 기반 아이콘/썸네일 | Mia 0.5일 | 수 오후 | Mia의 원래 빈 슬롯, `받는 일` 아트 |

- `A. 스왑`: 상점 미리보기로 B2를 대체하고 P0를 유지(위와 같이 시간·권한 확인 후 가능).
- `B. 범위 더 줄임`: 추가 아이콘을 만들지 않고 기존 리소스만 재사용해 Ben이 화면을 구성(아트 자산 재사용이 가능할 때만). QA와 G3 조건 동일.

- **T1 성공:** PM의 목표 결정 한 번만 요구하고, 에이전트가 합리적 스왑이나 범위 조정안을 생성하며 P0·Q2·G3·권한을 지킨다. AI가 다른 유효한 대안을 내놓아도 성공으로 판단할 수 있다. **최종 적용이 필요한 UI라면 승인 전에는 '제안' 상태**로 둔다.

## (2) T2 - Absorb a handoff slip

Mia 입력 :  제 보스 그림 A1은 화요일 오후 러프까지는 전달할 수 있지만, 수요일 오전에는 마무리 작업을 할 수 없게 됐어요. **최종본은 수요일 오후에 전달하겠습니다.** 제 작업 인계 지연을 조정해 주세요.

- 예상 수정 일정

| Task | 기존 | 수정 | 충돌/의존성 검증 |
| --- | --- | --- | --- |
| A1 | 화 오후 + 수 오전 | 화 오후 러프 + **수 오후 최종** | Mia 수 오전은 비움, 수 오후는 원래 비어 있음 |
| G2 | 수 오후 + 목 오전 | 수 오후 **임시 연결** + 목 오전 **최종 반영** | G2 첫 반일은 화 오후 러프를 사용. 최종본이 수 오후 **끝에** 도착하여 목 오전 시작 전에 준비됨 |
| Q2 | 목 오후 + 금 오전 | **변경 없음** | G2 종료 후 Q2 시작 |
| G3 | 금 오후 | **변경 없음** | Zoe의 금 오전 최종 승인 후 빌드 |
| A2 | 목 오전 + 목 오후 | **변경 없음** | A1이 수 오후 끝나므로 시작 조건 충족 |
- **기대할 수 있는 다른 답변:** Leo가 임시 연동을 거부하면 최종본 도착 후 G2를 착수하는 안은 통합 QA 목 오후 시작과 충돌한다. 이 경우 **성공 합의라고 꾸미지 말고 자동 복구 실패로 표시**한다. 다른 안을 제안하더라도 사용 가능한 작업 슬롯, 추가 인력의 스키마 및 직접 확인 조건을 모두 다시 검증해야 한다.
- **T2 성공:** 작업 연결에 참여한 **Mia·Leo·Zoe agent 3개**, **PM 의사결정 0회**, 인계 조건이 실질적으로 달라지는 **Leo 본인 확인 1회**, P0 품질·마감 유지. **agent에게 정보를 전달하는 것과 사람에게 승인을 요청하는 것은 다른 행위**로 구분하여 로깅한다.

| S1 진행률 | 50% | **75%** (커밋과 본인 추정 근거) |
| S1 남은 시간 | 화 오후 0.5일 슬롯에 배정 | **2시간**으로 재추정, **화 오후 슬롯 안에서 완료 가능** |
| S1 인계 약속 | 화 오후 완료 | **그대로** |
| S2 | 수 오전~수 오후 | **그대로** |
| 연락 대상 | — | **Sam agent만**. Zoe·Leo·Ben·Mia agent 호출 **0** |
| PM 결정 | — | **0회** |
- **T3 성공:** 증빙에 기반해 소유자 agent만 재추정하고, 인계 시간이 그대로면 다른 agent를 불필요하게 호출하지 않는다. **진척 75%는 작성자 주장/코드·테스트 근거를 확인한 추정**이지 커밋 하나로 자동 증명되는 절대적 사실이 아니다. 근거가 없으면 수치를 생성하지 않고 소유자에게만 확인한다. 남은 작업이 1일로 늘어 약속이 깨졌다는 증빙이 나오면 T3는 *약속 초과 탐지*까지만 하고 **별도 T2 실행**으로 넘긴다.
