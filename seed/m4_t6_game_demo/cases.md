# 2. 대표 시연 : 하나의 사건으로 task 수행

시연 사건 : Zoe의 목요일 오후 Q2 스모크 테스트 수행 불가

## (1) 담당자의 상황 보고

Zoe → 제가 목요일 오후 Q2 스모크 테스트를 수행할 수 없습니다. 그 작업을 다른 적격자에게 넘기는 데 동의합니다. 금요일 오전 최종 회귀 테스트와 서명은 제가 맡을 수 있습니다.

## (2) T1

PM → Q2에 등록된 수행 불가 조건이 27일 17시 데모까지 어떤 인계와 작업에 영향을 주는지 보여주세요.

- 기대 화면 결과

| 발견 대상 | 왜 연관되는가? | 에이전트의 올바른 판단 |
| --- | --- | --- |
| **Zoe / Q2 스모크(목 PM)** | 현재 담당자에게 새 수행 불가 조건 | **확정 충돌**. 원래 일정 그대로는 실행 불가 |
| **Zoe / Q2 최종 회귀(금 AM)** | 스모크 완료 후 진행해야 함 | 현재 담당자·시간은 유지 가능. 단 스모크를 먼저 해결해야 함 |
| **Leo / G3 빌드(금 PM)** | Q2 최종 승인 후 빌드 시작 | Q2 미해결이면 **후속 인계 위험**. 현재 직접적인 Leo 시간 중복은 없음 |
| **Ben / 대체 후보** | 스모크 QA 가능, 목 PM 빈 슬롯 | 후보로 검토 가능. **P0 소유권 변경 직접 확인** 필요 |
| **Sam / 대체 후보** | 테스트 가능, 목 PM엔 기존 S3 업무 | 후보로 검토 가능. **QA는 받는 일 밖 → 직접 수락**, S3 이동 검토 필요 |
| **Mia / A1·A2** | 이 사건의 변경과 직접 연결 없음 | **불필요한 협상 호출 금지** |
- T1 성공 판정 : `Q2 목 PM 실행 불가 → Q2 금 AM 회귀 위험 → G3 금 PM 인계 위험`을 보이고, **원인을 일으킨 사람·후속 인계·대체 후보**를 구분한다. 계획 선택·적용은 아직 하지 않는다. 대체 인력 탐색은 관련 스키마 조회로 한정하고, 무관한 사람의 agent에게 전체 협상을 방송하지 않는다.

## (3) T2

PM (화면 동작 또는 짧은 입력) → 이 영향 범위 안에서 해결 가능한 계획을 협상해 주세요. 담당자 확인이 꼭 필요한 경우에만 질문을 올려 주세요.

- 에이전트별 권한과 협상 논리
1. **Zoe agent**: 스모크 이관에 대한 본인 의사를 이미 기록했고, 금 오전 Zoe 회귀·서명 조건을 유지한다.
2. **Ben agent**: 목 PM 빈 슬롯, 스모크 수행 가능. 다만 P0 담당 조정이므로 **Ben 본인에게 직접 수락 요청**한다.
3. **Sam agent**: 목 PM은 랭킹 S3와 충돌한다. S3 전체를 **금 오전·오후**로 옮기면 슬롯이 확보되지만, Sam의 `받는 일`에 테스트가 없으므로 **Sam 본인에게 `QA 예외 수락 + 본인 S3 이동`을 묶어 확인**한다.
4. **Leo agent**: G3는 Q2 최종 서명이 금 오전 끝에 유지된다면 그대로 가능하다. Leo의 시간·담당 작업이 바뀌지 않으므로 **사람 Leo를 불필요하게 확인 호출하지 않는다**.
5. **Mia agent**: 이 건에 직접 연결되지 않으므로 협상에 참여하지 않는다.

- T2에서 검토 가능한 3가지 후보

| 후보 | 목 PM Q2 스모크 | 다른 변경 | 실제 필요한 수락 | 일정 판정 | T3 노출 조건 |
| --- | --- | --- | --- | --- | --- |
| **A — Ben 이관 (권장)** | **Ben** | Zoe 금 AM 회귀, 나머지 B0 유지 | **Ben 직접 승인**, Zoe의 기존 이관 동의 | **슬롯·의존성 통과** | 승인 완료 시 선택 가능 |
| **B — Sam 이관 + 랭킹 이동** | **Sam** | S3를 **금 AM+PM**으로 전체 이동. 랭킹은 기본 flag OFF, 데모 미포함 | **Sam 직접 승인**(QA 예외+S3 이동), Zoe 이관 동의 | **슬롯·의존성 통과**, 랭킹과 P0 독립성 필요 | 승인 완료 시 선택 가능 |
| **C — Ben↔Zoe 실제 업무 스왑** | **Ben** | Ben의 B2 메뉴 1일을 **Zoe 수 PM+목 AM**에 이관 | **Ben의 P0 인수 승인 + Zoe의 UI 예외 수락** 및 **Zoe UI 작업량 1일 재추정 검증** | **시간표만 통과**. Zoe가 UI 1일 내 완료할 수 있다는 보장은 **없음** | **작업시간 재추정과 양측 동의가 끝난 경우에만** 선택 가능 |

## (4) T3

PM의 화면 동작 → T2에서 `동의 완료`인 대안만 **최대 세 개** 비교하고 하나를 선택한다. 합의된 후보가 하나뿐이면 **하나만** 표시한다. 모두 거절됐으면 `적용 가능한 합의안 없음`으로 표시한다.

- PM 선택 예시 : 동의가 끝난 **A를 선택**한다. 그다음 화면에서는 `Q2 목 PM 스모크: Zoe → Ben`만 변경되고, `Q2 금 AM 회귀: Zoe`와 `G3 금 PM: Leo` 및 다른 작업은 유지되어야 한다.
- **적용 중 재확인 0회:** T2 때 관련자들이 **이 정확한 계획의 버전·담당·시간·작업량**에 합의했다는 기록이 있어야 한다. T3 선택 직후 별도 승인 팝업이 또 뜨면 목표와 맞지 않는다.
- **되돌리기 1회:** PM이 Undo를 누르면 방금 적용한 `Q2 스모크 담당 변경`만 되돌린다. **Zoe가 목 PM 작업을 못 한다는 원래 보고 사실을 지우면 안 된다.** Undo 후 원래 스모크 배정은 다시 `충돌·재계획 필요` 상태로 보여줘야 일관적이다.

정리하면 다음과 같다.

**T1:** Zoe가 자신의 Q2 작업 수행 불가를 보고한 상태. PM은 작업 카드에 한 줄만 써서 어떤 인계가 끊기는지 확인.

**T2:** 그 영향 범위에서 Ben과 Sam의 스키마·일정을 바탕으로 에이전트가 협상하고, 실제로 필요한 본인 승인만 받음.

**T3:** 동의가 끝난 계획만 비교합니다. 하나를 고르면 추가 확인 없이 적용되고, 되돌리면 적용한 계획만 취소.
